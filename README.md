# Iqra — apprendre à lire le Coran

Application Windows pour apprendre à lire le Coran avec la bonne prononciation : alphabet avec prononciation des lettres, lettres et voyelles, leçons de tajwîd, lecture des 114 sourates avec récitant (verset par verset et mot par mot), exercices.

Une application **Sensei Dev**.

**32 ou 64 bits ?** Ouvrez *Paramètres → Système → Informations système* et regardez « Type du système ». En cas de doute, la version 32 bits fonctionne aussi sur un ordinateur 64 bits.

Configuration : Windows 10 ou 11. Internet est nécessaire pour l'audio des versets et des mots ; le texte, les leçons et la prononciation des lettres fonctionnent hors ligne.

## Installation

1. Téléchargez et ouvrez l'installateur.
2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires**, puis **Exécuter quand même** (application récente non signée).
3. Suivez l'assistant : aucun droit administrateur n'est demandé. Un raccourci est créé sur le Bureau et dans le menu Démarrer.
